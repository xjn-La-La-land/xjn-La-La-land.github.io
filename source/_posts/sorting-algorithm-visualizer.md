把排序算法里的数组画成一排柱子，再用两个机械抓钩演示比较和交换，循环里发生的事情就能直接看到了。

这个演示支持冒泡、选择、插入、归并、快速、堆、希尔、梳和计数排序。除了切换算法、修改输入数组，还可以在 Monaco 编辑器里修改 C++ 代码，观察改动后的执行过程。

## 怎么使用

1. 在左侧资源管理器中选择算法文件，切换代码和对应动画。
2. 输入数组，点击“应用”；也可以随机生成一组数据。
3. 用播放、暂停和单步按钮观察过程。单步按比较、交换阶段或写入等实际动作推进。
4. 修改 C++ 代码后，点击“编译并演示”，让新的执行轨迹控制动画；点击“运行”则只编译执行并查看输出。

## 动画如何跟随代码

代码通过浏览器内的 WASM 工具链编译运行。系统自动识别比较、交换和数组写入的位置，记录执行轨迹，再交给动画播放。因此，动画展示的是当前代码的实际执行过程，而不只是预先写好的排序步骤。

比较、交换适合用两个抓钩来表现；归并排序和计数排序中的数组写入，则使用写入动作展示，不把它们强行画成两两交换。

首次运行需要加载约 58 MiB 的编译工具链，之后可利用浏览器缓存。在线编辑使用浏览器草稿模式，不会修改 GitHub 仓库里的 C++ 文件；需要保留修改时，可以点击“导出草稿”。
