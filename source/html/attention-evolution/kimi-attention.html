Kimi Attention 机制演进：MLA、KDA、Gated MLA 与 AttnRes

基于 Kimi K2、Kimi Linear 与 Kimi K3 官方技术报告，整理 MLA、KDA 递推与 chunkwise 算法、NoPE、Gated MLA、AttnRes 及混合缓存机制。

Kimi K2 / Kimi Linear / Kimi K3 · 官方技术报告

阅读范围。本文整理 Kimi K2、Kimi Linear 与 Kimi K3 官方技术报告中，与语言模型 backbone 的 attention、位置编码、跨层聚合和推理状态直接相关的内容。公式采用报告中的列向量约定，原图保留英文标签。补充推导以“整理者说明”标出。视觉 encoder、MoE 路由与通用训练流程仅在说明模块关系时涉及。

1. 演进主线与模块分工

Kimi K2 在全部 attention 层中使用 Multi-head Latent Attention（MLA），通过压缩每个历史位置的 K/V 表示降低 KV cache 占用。Kimi Linear 将大部分 MLA 层替换为 Kimi Delta Attention（KDA）：每层以固定大小的矩阵状态保存历史，同时保留少数 full MLA 层处理全局检索。Kimi K3 延续这种混合布局，修改 KDA 的门控，在 MLA 输出上增加门控，并用 Attention Residuals（AttnRes）选择跨层传递的表示。

1.1 技术路线与产品版本

Kimi Linear 是用于研究混合 attention 的独立模型，发布版本为 48B 总参数、3B 激活参数。它与 K2 的 1T 量级模型不是同一个 checkpoint 的前后版本。本文的演进关系表示机制之间的继承；K2-Thinking、K2.5、K2.6 和 K2.7 Code 的版本升级不能据此解释为采用了 KDA。

1.2 三种不同的状态

这些机制保存和读取的对象不同：

  • MLA KV cache 按历史 token 位置保存 latent 表示，长度随上下文增长；global attention 从中检索内容。
  • KDA recurrent state 是每个 head 的矩阵 St∈ℝdk×dvS_t\in\mathbb{R}^{d_k\times d_v}，历史通过衰减和 delta-rule 更新汇入该矩阵。每层还保留 ShortConv 所需的局部状态。
  • AttnRes block representation 汇聚同一个 token 在网络不同深度上的表示。它沿 layer/block 维度组织，不承担 KDA 的时间递推或 MLA 的历史 token 缓存职责。

整理者说明：KDA 层的状态大小与序列长度无关，但混合模型仍含 global MLA，因此整个模型的 KV cache 仍随序列长度增长。

2. Kimi K2：MLA 与 attention head 的计算成本

来源：Kimi K2 Technical Report，§2.1，原文 p.3–4；§2.3、表 2、图 6，原文 p.6–7。本报告印刷页码与 PDF 物理页码相同。

2.1 MLA 压缩每个历史位置的表示

K2 的架构与 DeepSeek-V3 相近，使用 MLA 作为 attention 机制，hidden dimension 为 7168。K2 报告没有重新给出 MLA 的完整推导；§2.1 明确区分了 head-specific content 分量 qC,kCq^C,k^C、head-specific rotary 分量 qRq^R，以及各 head 共享的 rotary key kRk^R。

整理者说明：下面用简化的单 token 记号说明低秩表示与 attention 的关系；它不是 K2 报告中的编号公式。省略 projection normalization 等实现细节。对于输入 xtx_t，content key 和 value 由共享 latent 生成：

ctKV=WDKVxt,kt,hC=WhUKctKV,vt,h=WhUVctKV.c_t^{KV}=W^{DKV}x_t,\qquad k_{t,h}^{C}=W_h^{UK}c_t^{KV},\qquad v_{t,h}=W_h^{UV}c_t^{KV}.

MLA 将 content 与 rotary 分量拼接。对第 hh 个 head，token tt 对历史位置 jj 的得分由两个内积组成：

ℓt,j,h=(qt,hC)Tkj,hC+(qt,hR)TkjRdC+dR,ot,h=∑j≤tSoftmaxj(ℓt,j,h)vj,h.\ell_{t,j,h}=\frac{(q_{t,h}^{C})^{\mathsf T}k_{j,h}^{C}+(q_{t,h}^{R})^{\mathsf T}k_j^{R}}{\sqrt{d_C+d_R}}, \qquad o_{t,h}=\sum_{j\le t}\operatorname{Softmax}_{j}(\ell_{t,j,h})v_{j,h}.

Decode 时可缓存 cjKVc_j^{KV} 与共享的 kjRk_j^R，并通过矩阵吸收避免显式展开全部 head-specific K/V。例如，content score 可以写为 ((WhUK)Tqt,hC)TcjKV((W_h^{UK})^{\mathsf T}q_{t,h}^{C})^{\mathsf T}c_j^{KV}。K2 报告所说“推理时不完整物化 Key 矩阵”，对应的就是这种执行形式。

每个位置的缓存更小，但 softmax 仍覆盖全部可见历史位置。固定维度下，处理长度为 TT 的序列仍有二次的 attention 计算项；单步 decode 仍需扫描长度为 TT 的历史。

2.2 从 128 个 head 减到 64 个

K2 将 DeepSeek-V3 的 128 个 attention head 减为 64 个，层数保持 61。报告给出的理由是长上下文推理成本：当 routed expert 总数固定为 384、序列长度为 128K 时，head 数从 64 增至 128 会使推理 FLOPs 增加 83%。在相同训练 token 数下，增加 head 数带来的 validation loss 改善约为 0.5%–1.2%。

83% 描述的是 FLOPs 增长，不能直接换算为某个硬件上的延迟增长。减少 head 数后，MLA 的 softmax 定义保持不变。

2.3 QK-Clip 控制 logit 增长

Kimi K2 引入 QK-Clip，是为了让 Muon 优化器在大规模模型训练中保持稳定，抑制 attention logits 持续增大所带来的 loss 突增和训练发散风险。

Attention logit 是什么，为什么过大会影响训练

Attention 先计算 query 与 key 的相似度，再用 softmax 将得分转换为权重。用普通单 head attention 的记号表示：

ℓij=qiTkjdh,pij=Softmaxj(ℓij).\ell_{ij}=\frac{q_i^{\mathsf T}k_j}{\sqrt{d_h}}, \qquad p_{ij}=\operatorname{Softmax}_{j}(\ell_{ij}).

这里的 logit 就是 softmax 之前的 QK 得分。训练时，生成 Q/K 的 projection 权重也在更新；如果这些权重的尺度持续增大，Q/K 内积及不同位置之间的得分差异就可能随之放大。Softmax 对得分差异敏感，分布会变得更尖锐。

整理者说明：下面是一个数值示例。把同一组得分放大十倍，attention 就从分散关注变成几乎只关注得分最高的位置：

Softmax([2,1,0])≈[0.665,0.245,0.090],\operatorname{Softmax}([2,1,0])\approx[0.665,0.245,0.090],
Softmax([20,10,0])≈[0.99995,0.000045,0].\operatorname{Softmax}([20,10,0])\approx[0.99995,0.000045,0].

例子中的变化来自得分差异被放大；给所有得分加同一个常数不会改变 softmax。分布趋于饱和会改变梯度传播，过大的中间值也会增加有限精度计算的风险。持续失控的 logit 增长因此会给训练带来不稳定性。

K2 为什么专门设计 QK-Clip

K2 选择 Muon，是因为此前 Moonlight 实验表明：相同模型规模和训练计算预算下，Muon 能比 AdamW 取得更好的效果。但扩大模型规模后，团队观察到 attention logits 爆炸，而且这种现象在使用 Muon 时比 AdamW 更频繁。

报告图 2 的中等规模实验使用 53B 总参数、9B 激活参数的 MoE。使用普通 Muon 时，最大 attention logit 很快超过 1000；报告将这类增长与 loss spike、偶发的训练发散联系起来。团队还发现，通常只有少数 head 出现异常，因此希望只干预这些 head。

已有方法各有局限：

  • Logit soft-cap： 限制送入 softmax 的得分，但生成这些得分的原始 QK 内积仍可能继续增大。
  • QK-Norm： 直接归一化 Q/K，但 MLA 的高效推理路径不显式生成各 head 的完整 key，难以直接加入这种归一化。

K2 因此选择控制生成 Q/K 的 projection 权重尺度，并将 QK-Clip 与 Muon、weight decay 和一致的更新 RMS scaling 整合为 MuonClip。

QK-Clip 做了什么

一句话描述。每次优化器更新后，QK-Clip 根据本轮各 attention head 的最大 logit，对超过阈值的 head 按比例缩小其 Q/K projection 权重，抑制后续计算中的 logit 增长。

对一个 training batch ℬ\mathcal{B}，记录第 hh 个 head 的最大 softmax 输入：

Smaxh=1dhmaxX∈ℬmaxi,jQih(Kjh)T,γh=min(1,τSmaxh).S_{\max}^{h}=\frac{1}{\sqrt{d_h}}\max_{X\in\mathcal{B}}\max_{i,j}Q_i^h(K_j^h)^{\mathsf T}, \qquad \gamma_h=\min\left(1,\frac{\tau}{S_{\max}^{h}}\right).

上式沿用报告的比例写法；算法 1 的执行条件是 Smaxh>τS_{\max}^{h}>\tau 时才计算缩放并裁剪，其余情况不修改权重。K2 使用 τ=100\tau=100。

MLA 的 clipping 只作用于 head-specific projection：

WhqC←γhWhqC,WhkC←γhWhkC,WhqR←γhWhqR.W_h^{qC}\leftarrow\sqrt{\gamma_h}W_h^{qC},\qquad W_h^{kC}\leftarrow\sqrt{\gamma_h}W_h^{kC},\qquad W_h^{qR}\leftarrow\gamma_hW_h^{qR}.

共享的 kRk^R 路径保持原值，以免一个异常 head 的裁剪影响其他 head。这样，content 内积与 rotary 内积都按 γh\gamma_h 缩放。QK-Clip 使用当前 forward 记录的最大 logit 作为信号，在参数更新后执行，不改写已经完成的本轮 forward/backward。

缩放示例：最大 logit 为 400，阈值为 100

整理者说明：若某个 head 的最大 logit 为 400，目标阈值为 100，缩放系数为：

γh=100400=0.25,γh=0.5.\gamma_h=\frac{100}{400}=0.25,\qquad\sqrt{\gamma_h}=0.5.

对于普通 QK 内积，把生成 Q 和 K 的权重各乘 0.5，两边相乘就使得分尺度变为原来的 0.25。MLA 含有共享的 rotary key，因此按上面的公式处理：content Q/K 的 projection 各乘 0.5，rotary Q 的 projection 乘 0.25，共享 rotary K 保持原值。两部分得分都按相同的比例缩小。

这个例子说明权重缩放对 QK 得分尺度的作用。实际训练使用本轮 forward 记录的最大 logit，在优化器更新后处理权重；它不保证下一批数据的最大 logit 恰好等于 100，后续 batch 仍需继续监测并按条件裁剪。

3. Kimi Linear：从标量遗忘到 channel-wise KDA

来源：Kimi Linear Technical Report，§2.1–2.2，原文 p.3；§3，原文式 (1)，p.4。本文为不同报告的公式增加 KL／K3 前缀，以保留原编号并避免重名。

3.1 Delta rule 更新 key 对应的映射

以下按报告的布局取 qt,kt∈ℝdkq_t,k_t\in\mathbb{R}^{d_k}、vt,ot∈ℝdvv_t,o_t\in\mathbb{R}^{d_v}，St∈ℝdk×dvS_t\in\mathbb{R}^{d_k\times d_v}。StTkS_t^{\mathsf T}k 表示用 key 从矩阵状态中读出的 value。

DeltaNet 对当前 key–value 对的重建误差做一次梯度下降：

ℒt(S)=12‖STkt−vt‖22,St=(I−βtktktT)St−1+βtktvtT.\mathcal{L}_t(S)=\frac12\|S^{\mathsf T}k_t-v_t\|_2^2, \qquad S_t=(I-\beta_t k_tk_t^{\mathsf T})S_{t-1}+\beta_t k_tv_t^{\mathsf T}.

它沿当前 key 方向修正读出的 value，更新量取决于“目标 value 与已有记忆预测值的差”。Gated DeltaNet（GDN）在此基础上增加一个 head 内共享的标量 retention factor αt\alpha_t：

St=αt(I−βtktktT)St−1+βtktvtT.S_t=\alpha_t(I-\beta_t k_tk_t^{\mathsf T})S_{t-1}+\beta_t k_tv_t^{\mathsf T}.

标量 αt\alpha_t 对状态的所有 key channel 使用同一个衰减比例。KDA 将它改为向量，使不同 channel 可以保留不同时间跨度的信息。

3.2 KDA 的更新顺序

KDA 的核心递推是：

St=(I−βtktktT)Diag(αt)St−1+βtktvtT,ot=StTqt.S_t=(I-\beta_t k_tk_t^{\mathsf T})\operatorname{Diag}(\alpha_t)S_{t-1} +\beta_t k_tv_t^{\mathsf T}, \qquad o_t=S_t^{\mathsf T}q_t.
(KL-1)

整理者说明：把式 (KL-1) 拆开，可以直接看清执行顺序和维度：

S¯t=Diag(αt)St−1,v^t=S¯tTkt,St=S¯t+βtkt(vt−v^t)T.\bar S_t=\operatorname{Diag}(\alpha_t)S_{t-1},\qquad \hat v_t=\bar S_t^{\mathsf T}k_t,\qquad S_t=\bar S_t+\beta_t k_t(v_t-\hat v_t)^{\mathsf T}.

αt∈(0,1)dk\alpha_t\in(0,1)^{d_k} 作用于矩阵的 key-channel 维，即此布局下的行；βt\beta_t 是每个 token、每个 head 的标量写入强度。衰减发生在重建误差计算之前，输出读取的是当前 token 已写入的 StS_t。

3.3 从 hidden state 生成 Q/K/V 与门控

Kimi Linear 对每个 head 的 Q/K/V projection 应用 ShortConv 和 Swish，并对 Q/K 进行 L2 normalization：

qth,kth=L2Norm(Swish(ShortConv(Wq/khxt))),vth=Swish(ShortConv(Wvhxt)).q_t^h,k_t^h=\operatorname{L2Norm}\!\left(\operatorname{Swish}\!\left(\operatorname{ShortConv}(W_{q/k}^h x_t)\right)\right), \qquad v_t^h=\operatorname{Swish}\!\left(\operatorname{ShortConv}(W_v^h x_t)\right).
αth=f(Wα↑Wα↓xt),βth=Sigmoid(Wβhxt).\alpha_t^h=f(W_\alpha^{\uparrow}W_\alpha^{\downarrow}x_t), \qquad \beta_t^h=\operatorname{Sigmoid}(W_\beta^h x_t).

报告的实验使用 dk=dv=128d_k=d_v=128。衰减 projection 采用低秩参数化，中间 rank 等于 head dimension。ShortConv 捕获局部 token 依赖；Q/K 的 L2 normalization 用于控制状态转移的谱性质。

在 output projection 之前，KDA 对每个 head 的输出做 RMSNorm，再应用 sigmoid gate。原文式 (10) 为：

ot=Wo[Sigmoid(Wg↑Wg↓xt)⊙RMSNorm(KDA(qt,kt,vt,αt,βt))].o_t=W_o\left[\operatorname{Sigmoid}(W_g^{\uparrow}W_g^{\downarrow}x_t) \odot\operatorname{RMSNorm}(\operatorname{KDA}(q_t,k_t,v_t,\alpha_t,\beta_t))\right].
(KL-10)

这里的 output gate 同样采用低秩 projection。它调节向下一层输出哪些 channel；αt\alpha_t 则控制写入前保留多少旧状态。报告将二者放在不同位置，承担不同职责。

3.4 与 DPLR 的关系

来源：Kimi Linear §3.2、§6.2，原文 p.5、14–15。

一般 Diagonal-Plus-Low-Rank（DPLR）转移使用 D−atbtTD-a_tb_t^{\mathsf T}。KDA 的状态转移可写为：

(I−βtktktT)Dt=Dt−atbtT,Dt=Diag(αt),at=βtkt,bt=αt⊙kt.(I-\beta_t k_tk_t^{\mathsf T})D_t =D_t-a_tb_t^{\mathsf T},\qquad D_t=\operatorname{Diag}(\alpha_t),\quad a_t=\beta_t k_t,\quad b_t=\alpha_t\odot k_t.

这是将两个 rank-1 因子绑定到同一个 key 的受约束 DPLR。对角衰减在转移矩阵的右侧，因此它先作用于旧状态；通常不能与 I−βtktktTI-\beta_t k_tk_t^{\mathsf T} 交换顺序。

报告的 §6.2 和 Listing 8 比较指出，这种绑定把需要 secondary chunking 的矩阵构造从四组减为两组，并在跨 chunk 状态及输出计算中减少约三次矩阵乘法。图 2 在 batch size 为 1、16 个 head、最长 64K 序列的 kernel 对比中报告接近 2 倍的速度。该结果针对 KDA 与通用 DPLR kernel，不是完整模型的端到端加速比。

4. KDA 的 chunkwise 并行形式

来源：Kimi Linear §3.1，原文式 (2)–(9)，p.4–5；Kimi K3 §2.1.1，原文式 (3)–(4)，p.4。

逐 token 递推让每一步依赖前一步的 StS_t。Chunkwise 算法把序列分成长度为 CC 的 chunk：chunk 内的量可由 token 输入并行计算，chunk 之间传递矩阵状态。WY 表示将连续 rank-1 更新压缩为稠密表示；UT transform 进一步将辅助量的递推转成下三角求解和矩阵乘法。

4.1 累积衰减与辅助量

为简化下标，本节省略 chunk 索引。SinS_{\mathrm{in}} 是进入当前 chunk 的状态；Q,K∈ℝC×dkQ,K\in\mathbb{R}^{C\times d_k}、V∈ℝC×dvV\in\mathbb{R}^{C\times d_v} 按行存放 chunk 内的向量。定义：

γi=∏r=1iαr,G=[γ1T⋮γCT],Dβ=Diag(β1,…,βC).\gamma_i=\prod_{r=1}^{i}\alpha_r,\qquad G=\begin{bmatrix}\gamma_1^{\mathsf T}\\\vdots\\\gamma_C^{\mathsf T}\end{bmatrix}, \qquad D_\beta=\operatorname{Diag}(\beta_1,\ldots,\beta_C).

所有衰减乘积、除法和 ⊙\odot 都按 channel 逐元素计算。GG 对应报告的 Γ[t]1→C\Gamma_{[t]}^{1\to C}。依照原文式 (6)–(7)，UT transform 写成：

M=[I+StrictTril(Dβ(G⊙K)(K/G)T)]−1Dβ,M=\left[I+\operatorname{StrictTril}\!\left(D_\beta(G\odot K)(K/G)^{\mathsf T}\right)\right]^{-1}D_\beta,
(KL-6)
W=M(G⊙K),U=MV.W=M(G\odot K),\qquad U=MV.
(KL-7)

W∈ℝC×dkW\in\mathbb{R}^{C\times d_k}、U∈ℝC×dvU\in\mathbb{R}^{C\times d_v}。StrictTril\operatorname{StrictTril} 只保留严格下三角，排除对角线，因此括号中的矩阵对角线为 1。实现时可以通过前代求解，公式中的逆矩阵不要求调用一般稠密矩阵求逆。

4.2 输出中的跨 chunk 与 chunk 内两项

先定义 pseudo-value：

V~=U−WSin.\widetilde V=U-WS_{\mathrm{in}}.

它扣除了旧状态对当前 key 的预测贡献。整个 chunk 的输出为：

O=(G⊙Q)Sin⏟inter-chunk+Tril((G⊙Q)(K/G)T)V~⏟intra-chunk.O=\underbrace{(G\odot Q)S_{\mathrm{in}}}_{\text{inter-chunk}} +\underbrace{\operatorname{Tril}\!\left((G\odot Q)(K/G)^{\mathsf T}\right)\widetilde V}_{\text{intra-chunk}}.
(KL-9)

第一项读取进入 chunk 前的历史状态，第二项汇集当前 chunk 内各次更新的贡献。这里 Tril\operatorname{Tril} 包含对角线：按照式 (KL-1)，每个位置先更新状态，再产生自己的输出。K3 原文式 (4)明确说明了这一点。

4.3 输出状态与衰减区间

整理者说明：从式 (KL-1) 展开，第 ii 次写入在 chunk 结束时只经过第 i+1i+1 至 CC 步的后续衰减。定义 RR 的第 ii 行为 γC/γi\gamma_C/\gamma_i，可以得到与 token 递推一致的 outgoing state：

Ri,:=γC/γi=∏r=i+1Cαr,Sout=Diag(γC)Sin+(R⊙K)TV~.R_{i,:}=\gamma_C/\gamma_i=\prod_{r=i+1}^{C}\alpha_r, \qquad S_{\mathrm{out}}=\operatorname{Diag}(\gamma_C)S_{\mathrm{in}} +(R\odot K)^{\mathsf T}\widetilde V.

最后一行的后续衰减为空积，等于 1。这个边界也适用于单 token chunk：当前 value 写入后不应再乘一次当前 token 的遗忘系数。

原文下标核对。Kimi Linear 式 (8) 将状态更新中的缩放项写为 Γi→C，而 §2.1 将 γi→j 定义为包含起点 i 的乘积。若严格按该定义使用，会使第 i 次写入多衰减一次。上面的 γC/γi 形式为整理者推导，已与逐 token 递推核对输出及末状态；下图保留原文写法。

4.4 有限精度下的 secondary chunking

GG 由多个位于 (0,1)(0,1) 的因子连乘得到。当累积衰减很小时，K/GK/G 可能产生很大的中间值，即使最终所需的相对衰减仍在合理范围内，也可能发生溢出。

Kimi Linear 在 log space 计算相对衰减，并进一步切分 secondary tile。K3 对这一实现的回顾给出 tile 长度为 16 token：非对角 tile 可直接使用 Tensor Core matmul；对角 tile 仍需显式计算 position pair。这一对角路径成为 K3 修改衰减参数化的直接动机。

5. Kimi Linear：KDA 与 NoPE MLA 的混合架构

来源：Kimi Linear §4，原文 p.5–6；§5.2、表 1，p.8–9；表 5、§6.1，p.12–14。

5.1 为什么保留 full MLA

矩阵状态容量固定，使 KDA 的单步状态读写不随历史长度增长，但长上下文中的内容检索仍是纯 linear attention 的主要瓶颈。Kimi Linear 因此保留少量 global MLA 层，让这些层直接访问所有可见 token。

报告采用 layerwise hybrid，即交替放置不同类型的完整层。相对于在同一层内混合不同 head 的 headwise hybrid，这种组织方式更容易接入训练与推理基础设施，训练也更稳定。

3∶1 是报告采用的混合模式。其作用是减少随序列增长的全局 attention 层数量，同时保留跨任意位置检索内容的路径。不能据此将整个模型的 prefill 复杂度写成严格的线性复杂度。

5.2 NoPE 的位置敏感性来自哪里

所有 full MLA 层都使用 No Position Encoding（NoPE），不对 Q/K 施加显式位置编码。KDA 的数据相关状态转移和局部 ShortConv 负责位置敏感性及 recency bias，全局 MLA 则执行内容相关的交互。

整理者说明：由 KDA 递推展开，可以看见历史写入如何经过后来 token 的变换。令：

Ft=(I−βtktktT)Diag(αt).F_t=(I-\beta_t k_tk_t^{\mathsf T})\operatorname{Diag}(\alpha_t).

在初始状态为零时：

St=∑i=1t(FtFt−1⋯Fi+1)βikiviT,S_t=\sum_{i=1}^{t}(F_tF_{t-1}\cdots F_{i+1})\,\beta_i k_iv_i^{\mathsf T},
ot=∑i=1tβi[qtT(FtFt−1⋯Fi+1)ki]vi.o_t=\sum_{i=1}^{t}\beta_i\left[q_t^{\mathsf T}(F_tF_{t-1}\cdots F_{i+1})k_i\right]v_i.

较早的写入会经过更多后续转移；转移又依赖每个 token 的 key 与门控，因此该层对顺序和内容都敏感。Kimi Linear §6.1 将这种矩阵连乘与乘性位置编码联系起来。GDN 为每个 head 使用单一衰减尺度，KDA 则让不同 channel 具有不同的衰减行为。

NoPE 只描述 MLA 层不再显式给 Q/K 加位置编码。MLA 的输入已经经过位置敏感的 KDA 层，整个模型仍会使用序列顺序信息。K3 延续这一分工，扩展上下文时不需要为 MLA 重新调整 RoPE frequency base 或应用 YaRN。

6. Kimi K3：修改衰减范围与输出门控

来源：Kimi K3 Technical Report，§2.1，原文 p.3–6；表 1，p.11。

K3 将“3 层 KDA + 1 层 Gated MLA”的模式重复 23 次，并在 backbone 末尾再放置一层 Gated MLA，使最后一层执行全局 attention。总计 69 层 KDA、24 层 Gated MLA，共 93 层。每个 attention 层后都接 channel-mixing 网络；Stable LatentMoE 的内部路由不在本文范围内。

6.1 Lower-bounded decay 约束中间值范围

K3 保留式 (KL-1) 的 KDA 递推。变化发生在输入 xtx_t 如何生成 αt\alpha_t。衰减 logit 仍由低秩 projection 与 head-specific bias 生成：

zth=Wα↑Wα↓xt+bαh.z_t^h=W_\alpha^{\uparrow}W_\alpha^{\downarrow}x_t+b_\alpha^h.

Kimi Linear 采用负 Softplus 映射，其每步 log-decay 没有有限下界：

gth=−eAhSoftplus(zth),αth=exp(gth).g_t^h=-e^{A^h}\operatorname{Softplus}(z_t^h),\qquad \alpha_t^h=\exp(g_t^h).

K3 改用带固定下界的 scaled sigmoid：

gth=gminSigmoid(eAhzth)∈(gmin,0)dk,αth=exp(gth)∈(egmin,1)dk.g_t^h=g_{\min}\operatorname{Sigmoid}(e^{A^h}z_t^h)\in(g_{\min},0)^{d_k}, \qquad \alpha_t^h=\exp(g_t^h)\in(e^{g_{\min}},1)^{d_k}.
(K3-5)

AhA^h 是每个 head 可学习的 log-scale，初始化为 0；gmin=−5g_{\min}=-5 为固定值。各 channel 的 bias 按报告所引用的初始化方案设置。

当 gmin=−5g_{\min}=-5 时，αt,jh>e−5≈6.7×10−3\alpha_{t,j}^h>e^{-5}\approx6.7\times10^{-3}。在一个 16-token tile 内，累积 log-decay 位于 (−80,0)(-80,0)，对应的 reciprocal rescaling 小于 e80e^{80}，仍在 BF16 的动态范围内。报告据此让对角 tile 也采用稠密 Tensor Core matmul，移除显式 position-pair 计算路径。

整理者说明：这个数值界针对 16-token secondary tile，不能把它外推为整段 1M 上下文累积乘积的界。BF16 动态范围足够也不等于消除了所有舍入误差；该修改解决的是这里的溢出风险与对角 tile 执行方式。

6.2 KDA 的 output gate 改为 full-rank

Kimi Linear 在式 (KL-10) 中使用 Wg↑Wg↓W_g^{\uparrow}W_g^{\downarrow} 生成 output gate。K3 改为 full-rank、input-dependent projection WgxtW_gx_t：

yt=Wo[Sigmoid(Wgxt)⊙RMSNorm(o~t)].y_t=W_o\left[\operatorname{Sigmoid}(W_gx_t)\odot\operatorname{RMSNorm}(\widetilde o_t)\right].
(K3-6)

o~t\widetilde o_t 是 KDA recurrence 的输出，RMSNorm 按 head 执行。这里改为 full-rank 的是 output gate；生成 decay logits 的 projection 仍是低秩结构。

6.3 Gated MLA：NoPE 与逐 channel 输出门控

K3 的 global MLA 继续缓存低维 latent，并保留对全部可见位置的内容交互。它沿用 Kimi Linear 的 NoPE，不对 MLA 的 Q/K 施加显式位置编码。

在 MLA 的未门控输出 o~t\widetilde o_t 上，K3 增加与当前输入相关的 full-rank、channel-wise gate：

yt=Wo[Sigmoid(Wgxt)⊙o~t].y_t=W_o\left[\operatorname{Sigmoid}(W_gx_t)\odot\widetilde o_t\right].
(K3-7)

这个 gate 位于 attention 聚合之后、output projection 之前，用于调节从全局 attention 读出的各 channel。它不选择 Top-K token，也不缩短 global attention 的可见历史范围。原文式 (7) 没有 KDA 式 (6) 中显式列出的 head-wise RMSNorm，本文按原式保留这一差别。

训练时，为缓解 flash attention 中已知的有偏舍入误差，K3 将 attention output 保持为 FP32。这使 output tile 的片上占用加倍。报告据此重新安排训练 kernel：让 output tile 与 KV staging buffer 复用片上存储，而不是与 query tile 复用，为更深的 KV pipeline 留出空间。

6.4 Attention projection 的训练更新

来源：K3 §2.5、§3.3，原文 p.10–11。

K3 的 Per-Head Muon 将 Q/K/V projection 的 momentum matrix 沿 head 维度切分，分别进行 Newton–Schulz 正交化。相比对整个 projection matrix 一起正交化，这能减少 head 之间梯度或动量尺度差异对更新方向的影响。每个 head 的子矩阵也使该步骤的优化器开销略低。

报告的训练方案同时沿用 K2 引入的 weight-clipping 机制。Per-Head Muon 和 QK-Clip 作用于训练更新；KDA、Gated MLA 的门控则参与每次模型 forward。

7. AttnRes：沿网络深度选择历史表示

来源：Kimi K3 §2.2，原文式 (8)–(10)，p.6；§5.4.2 的 Block AttnRes 实现，p.24。

7.1 Full AttnRes 的 key、value 与 pseudo-query

常规 residual connection 将各层输出以固定权重相加。AttnRes 为每一层提供一个可学习的 pseudo-query，使该层能够按输入内容选择此前的表示。下文省略 token 索引；attention 的候选轴是网络深度。

对第 ll 层，ql=wl∈ℝdq_l=w_l\in\mathbb{R}^d 是该层独立的可学习参数。原文将 key 和 value 定义为：

ki=vi={h1,i=0,fi(hi),1≤i≤l−1.k_i=v_i=\begin{cases} h_1,&i=0,\\ f_i(h_i),&1\le i\le l-1. \end{cases}
(K3-8)

其中 h1h_1 是 token embedding，fi(hi)f_i(h_i) 是第 ii 层的输出。得分核对 key 先执行 RMSNorm，防止幅值较大的层输出支配 attention 权重：

ϕ(q,k)=exp(qTRMSNorm(k)),\phi(q,k)=\exp\!\left(q^{\mathsf T}\operatorname{RMSNorm}(k)\right),
αi→l=ϕ(ql,ki)∑j=0l−1ϕ(ql,kj),hl=∑i=0l−1αi→lvi.\alpha_{i\to l}=\frac{\phi(q_l,k_i)}{\sum_{j=0}^{l-1}\phi(q_l,k_j)}, \qquad h_l=\sum_{i=0}^{l-1}\alpha_{i\to l}v_i.
(K3-9)

Pseudo-query 是层参数，但 key 来自当前 token 的各层表示，所以权重仍然依赖输入。RMSNorm 用于评分路径，value 保留原表示。

Full AttnRes 的深度方向计算量为 𝒪(L2d)\mathcal{O}(L^2d)；报告指出，在 L<100L<100 时这一算术开销可以接受。实现开销主要来自同时保存所有层输出所需的 𝒪(Ld)\mathcal{O}(Ld) 空间，以及 pipeline parallelism 下的跨 stage 通信。这里讨论的是一个 token 在深度方向的成本，batch 与序列维度另计。

7.2 Block AttnRes 如何压缩候选集

Block AttnRes 将 LL 层分为 NN 个 block。Block 内仍将各层输出相加，得到 bnb_n；不同 block 之间才执行 attention。记 bni−1b_n^{i-1} 为当前 block 前 i−1i-1 层的 partial sum，并令 b0=h1b_0=h_1。

第 nn 个 block 中，第 ii 层可访问的 value 为：

V={[b0,b1,…,bn−1]T,i=1,[b0,b1,…,bn−1,bni−1]T,i≥2.V=\begin{cases} {[b_0,b_1,\ldots,b_{n-1}]}^{\mathsf T},&i=1,\\ {[b_0,b_1,\ldots,b_{n-1},b_n^{i-1}]}^{\mathsf T},&i\ge2. \end{cases}
(K3-10)

已经完成的 block 提供压缩后的历史表示，当前 block 提供正在累加的 partial sum。最终输出再汇聚所有 block 表示。状态存储与通信由 𝒪(Ld)\mathcal{O}(Ld) 降至 𝒪(Nd)\mathcal{O}(Nd)。

K3 使用 8 个网络 block，每个通常包含 12 层，末尾 block 不满 12 层；将 embedding 作为一个独立来源计入后，共有 9 个 block 来源。这个 12-layer AttnRes 分组与“3 KDA + 1 MLA”的 4-layer attention 模式是两个不同的划分。

7.3 Inter-block 与 intra-block 两阶段执行

报告使用两阶段调度：inter-block pass 批量读取已经完成的 block 表示；每一层再把当前 block 的 partial sum 通过 online-softmax merge 合入结果。这样，跨 block 的工作可以提前计算，随层推进变化的工作只处理当前 partial sum。

Prefill 时采用 sequence parallelism，避免在每个 TP rank 上重复物化同一 token 的 block 表示。具体做法是将 TP all-reduce 分解为 reduce-scatter 和 all-gather，把 intra-block kernel 放在两个 collective 之间，作用于序列切分后的 hidden states。

Decode 时，inter-block kernel 放到 side stream，与主 stream 上独立的计算重叠；intra-block 的结果合并、partial-sum 更新及后续 RMSNorm 则融合到前一个 TP all-reduce 中，减少独立 kernel launch 与内存访问。

8. 从混合 attention 到并行与 cache 管理

来源：Kimi K3 §5.1，原文 p.17–18；§5.4.1–5.4.2 的 KDA 部分，p.22–24。

8.1 Training 与 prefill 的并行划分

Chunkwise KDA 的 chunk 内计算并行、跨 chunk 状态传播有递推依赖。如果两个阶段简单交替，状态传播期间可能无法充分使用 SM。K3 的 FlashKDA 用不同的调度分别处理 token-parallel 计算和 head-parallel recurrence，将 chunk 内计算与跨 chunk 状态传播重叠。报告使用基于 CUTLASS 的实现，作为 FLA 可自动选择的 backend，覆盖训练和 inference prefill。

仅使用 tensor parallelism 会切分 head，但不会缩短每个 head 需要递推的序列。TP degree 较高时，每个 rank 只保留少量 head，超长 prefill 的 recurrence 可能缺乏并行度。报告因此在单设备内引入 SM-level context parallelism：多个 SM 分别计算不同序列片段的转移，再合并得到每段精确的起始状态。这一路径不涉及跨设备通信。

8.2 KDA context parallelism 必须传递转移矩阵

Vanilla linear attention 的状态是可相加的历史贡献。KDA 每一步会先变换已有状态，仅传递“片段从零状态产生的结果”不足以重建真实上下文。

整理者说明：把 K3 原文式 (17) 的分段计算写为 affine 形式，可以明确每个 rank 需要交换什么。对一个片段 ii，使用 §5.2 中的单 token 转移 FtF_t，定义：

Pi=FTi⋯F2F1∈ℝdk×dk,Hi=该片段从零初始状态产生的末状态.P_i=F_{T_i}\cdots F_2F_1\in\mathbb{R}^{d_k\times d_k}, \qquad H_i=\text{该片段从零初始状态产生的末状态}.

该片段对任意输入状态的作用为：

Sout,i=PiSin,i+Hi.S_{\mathrm{out},i}=P_iS_{\mathrm{in},i}+H_i.

两个相邻片段按先 aa 后 bb 的顺序组合，得到：

(Pb,Hb)∘(Pa,Ha)=(PbPa, Hb+PbHa).(P_b,H_b)\circ(P_a,H_a)=(P_bP_a,\ H_b+P_bH_a).

该组合满足结合律，可以做 prefix scan。报告的 KCP 实现让各 rank 先独立计算 PiP_i 和 HiH_i，再用一次 all-gather 交换两者；之后按文档内的片段顺序应用 S←PiS+HiS\leftarrow P_iS+H_i，恢复每个 rank 的输入状态。

与交换随 token 数增长的完整 KV block 相比，每个 head、每个片段交换的是固定形状的 dk×dkd_k\times d_k 转移和 dk×dvd_k\times d_v 状态。总通信仍受 rank 数、head 数和数据类型影响，不能将“固定形状”理解为通信量为零。

8.3 MLA 与 KDA 必须在同一 prefix 边界恢复

MLA 按 token 保存 KV；KDA 通常为每个请求维护一份随生成更新的 recurrent state。一次 prefix 命中只有在两类状态都能恢复到同一个边界时才可复用。

K3 将 KDA state 与 MLA KV 放进统一的 paged block pool，使用相同字节大小的 page，共用分配、引用计数和回收逻辑。Page 内按 head 连续存储状态，因此每个 head 的 byte stream 可独立传输。在 prefill/decode 分离且两端 TP degree 不同的情况下，layout 转换在传输路径上完成，无需在 GPU 上额外重排。

如果 prefix hash 的粒度被迫等于物理 block 粒度，为容纳大块 KDA state，block size 会被推到 1024–6144 token。短请求很难复用，chunked prefill 也要跨过整个物理 block 才能登记 prefix。K3 将两种粒度拆开：物理 block 仍负责分配；prefix hash 可以使用 512-token 小块。

MLA 的 partial page 以最后一个完整 hash block 的 chained hash 登记，页面填充后向后推进登记边界。每次 forward 后，KDA 保存本次处理范围内最后一个 hash 对齐位置的 checkpoint；随后被替代的中间 checkpoint 可以回收，对话轮次边界处的 checkpoint 则保留供后续请求复用。

查找分两步：先匹配 MLA 的完整物理 block，在第一个未命中的 block 内继续查 hash endpoint；再检查候选边界是否在所有 KDA cache group 中都有 checkpoint。最终选取满足两类条件的最长边界。原图示例中，前 2800 token 相同的请求在 B=2560=5×512B=2560=5\times512 处恢复，而不是跳到 2800。

整理者说明：hash 粒度为 512 token，不意味着每个 512-token 边界都永久保存 KDA checkpoint。正文明确采用稀疏 checkpoint；实际可复用边界仍取决于 checkpoint 是否存在。

8.4 共享缓存与并发调度的一致性

缓存中的 KDA checkpoint 是只读快照。命中后先复制到请求私有的运行状态，再执行 forward；新 checkpoint 写入新 slot，不能原地修改仍对其他请求可见的快照。

报告列出三个并发条件：

  1. 所有 cache group 共用 free list。在任何分配发生之前，先 pin 住全部 group 的命中 block，避免某个 group 的私有副本分配驱逐另一个 group 刚命中的 block。
  2. Copy-on-write 的 GPU 拷贝在 forward 前执行。当前调度步内新分配或登记、但拷贝尚未完成的 block 暂不参与匹配，避免读到前一所有者的数据。
  3. KDA checkpoint 必须在全部 group 中共同存在。驱逐一个 group 的 checkpoint 时，原子地使同一边界的其他 group checkpoint 失去可命中资格。

这些约束确保缓存标签代表的 token prefix 与实际 state 一致。Hash 匹配解决文本是否相同，checkpoint 与调度规则解决恢复的计算状态是否完整。

8.5 Speculative decoding 的 state replay

KDA decode 每一步会原地更新 recurrent state。MTP speculative decoding 若拒绝部分 draft token，状态可能已经越过最后一个 accepted token，不能像按位置索引 KV 那样直接截断。

为每个 draft 位置保存完整状态可以恢复，但会增加大量状态读写。K3 改为缓存更小的 projected inputs，在片上重新执行 accepted prefix 的递推，并写回已验证 token 与 bonus token 对应的状态。

Replay token、bonus token 与下一轮 draft window 在同一个 fused recurrent kernel 中处理，覆盖 ShortConv、输入 normalization、门控、KDA recurrence 和输出 normalization。Projected-input cache 留在 decode stage 内部，因此 prefix cache 和 prefill/decode 分离使用的传输 payload 与非 speculative serving 相同。

9.1 KDA 核心计算的复杂度

来源：Kimi Linear §6.3，原文式 (13)–(14)，p.15–16。

在非变长序列、单个 head、dk=dv=dhd_k=d_v=d_h 的设置下，报告对固定 chunk size C=64C=64 的 KDA kernel 给出：

FLOPsKDA(T;C,dh)=6Tdh2+3TCdh+TC2.\operatorname{FLOPs}_{\mathrm{KDA}}(T;C,d_h)=6Td_h^2+3TCd_h+TC^2.
(KL-13)

Full attention 的主要项为：

FLOPsAttn(T;dh)=2T2dh.\operatorname{FLOPs}_{\mathrm{Attn}}(T;d_h)=2T^2d_h.
(KL-14)

固定 C,dhC,d_h 后，KDA 核心随 TT 线性增长。报告将线性 projection 的计算与核心 attention 分开讨论；上述表达式不能当作包含 Q/K/V projection、ShortConv、MoE、normalization 和数据搬运的完整模型 forward 成本，更不能直接换算为实测运行时间。

整理者说明：对于含 nKn_K 个 KDA 层、nMn_M 个 MLA 层的混合模型，序列维度上的 prefill 计算可粗略写为 nK𝒪(T)+nM𝒪(T2)n_K\mathcal{O}(T)+n_M\mathcal{O}(T^2)。只要 nM>0n_M>0，完整模型仍保留二次项。少量 global 层降低的是该项的系数。

9.2 当前状态大小与保存多个 checkpoint 的成本

Kimi Linear 的每个 KDA head 维护 128×128=16384128\times128=16384 个状态元素。与不断增长的 KV cache 相比，当前 recurrent state 不随上下文增长；但元素占用的字节数由存储精度决定，ShortConv 也有独立的固定状态。

整理者说明：多请求服务中保存 prefix checkpoint 会保留同一层在多个边界上的状态副本。这部分存储随保留的 checkpoint 数量增长，不能用“每个 head 只有一个矩阵”估计整个 prefix-cache 池。
