MiniMax Attention 机制演进：Lightning Hybrid、Full GQA 与 MiniMax Sparse Attention（MSA）

基于 MiniMax-01、MiniMax-M2 Series 与 MiniMax Sparse Attention 官方技术报告整理的 Attention 机制中文技术文档

MiniMax-01 / MiniMax-M2 Series / MiniMax Sparse Attention 官方技术报告

阅读范围。本文依据 MiniMax-01、MiniMax-M2 Series 与 MiniMax Sparse Attention 三份官方技术报告，只整理 Text-01、M2、M3 的 attention 架构、选择依据和主要成本。MSA 的全称是 MiniMax Sparse Attention。hidden state、KV cache、prefill、decode、Top-K、indexer 等术语保留英文。

1. 三代主线

MiniMax 的路线在效率与完整历史访问之间有一次折返。Text-01 用 Lightning Attention 替代大部分 softmax 层；M2 的所有层恢复 full attention，并用 GQA 控制 KV cache；M3 引入 MiniMax Sparse Attention（MSA），先选择 KV blocks，再在选中范围内执行 softmax。

MiniMax Attention 机制演进主线
模型节点 Attention 结构 解决的问题 留下的问题
Text-01 7 层 Lightning + 1 层 full softmax，循环 10 次 大部分层不再形成完整 N×NN\times N attention matrix 纯 linear attention 检索能力不足；softmax 层仍有二次成本
M2 62 层 full causal GQA，48 Q heads / 8 KV heads 以完整历史覆盖保证复杂推理和长程 Agent 质量 Attention 计算仍随上下文长度二次增长
M3 / MiniMax Sparse Attention（MSA） GQA + block indexer + sparse softmax 每个 query/group 只读取 Top-K KV blocks 轻量 indexer 仍需扫描完整历史；selector 可能漏选

三者减少的成本不同：Text-01 改变 attention 的代数形式，M2 只减少 KV heads，MSA 缩小每次 softmax 的支持集合。

2. Text-01：Lightning Attention 与周期性 softmax

来源：MiniMax，MiniMax-01: Scaling Foundation Models with Lightning Attention，v1，报告 §2.2。

MiniMax-Text-01 有 80 层、64 个 attention heads，head dimension 为 128。每 7 个 Lightning Attention block 后接 1 个 softmax attention block，所以全模型包含 70 层 Lightning Attention 和 10 层 full softmax。Softmax 层采用 group size 为 8 的 GQA。

2.1 先区分报告示意式与实际算子

报告先用不带 causal mask 的 NormAttention 说明矩阵乘法可以重排。省略 feature activation、decay 和 gate 后：

O~=(QKT)V=Q(KTV),O=Norm(O~).\widetilde O=(QK^{\mathsf T})V =Q(K^{\mathsf T}V), \qquad O=\operatorname{Norm}(\widetilde O).
(T2)

这条等式只依赖矩阵乘法结合律。左边先形成 N×NN\times N 的 score matrix；右边先形成 d×dd\times d 的 state。当 d≪Nd\ll N 时，右乘路径避免了序列长度上的二次中间量。

说明。上式是 MiniMax-01 报告为讲解复杂度而写的非因果示意式，不是 Text-01 Lightning Attention 的完整定义。通用 kernelized linear attention 通常还会显式写 query/key 的 feature map 和归一化分母；Text-01 的实际实现则采用 SiLU 后的 Q/K/V、固定 exponential decay、RMSNorm 和 output gate。

2.2 Causal mask 为什么破坏一次性右乘

对非因果 attention，所有 query 都能共享同一个全局 state：

S=KTV=∑j=1NkjTvj,o~i=qiS.S=K^{\mathsf T}V=\sum_{j=1}^{N}k_j^{\mathsf T}v_j, \qquad \widetilde o_i=q_iS.
(T3)

Causal attention 中，第 ii 个 query 只能读取 j≤ij\le i 的 token。每个位置需要不同的 prefix state：

Si=∑j=1ikjTvj,o~i=qiSi.S_i=\sum_{j=1}^{i}k_j^{\mathsf T}v_j, \qquad \widetilde o_i=q_iS_i.
(T4)

如果仍使用一次性计算的全局 KTVK^{\mathsf T}V，那么 qiq_i 会读到 j>ij>i 的未来 token。矩阵形式上，causal mask 作用在 QKTQK^{\mathsf T} 的每一行，不能穿过乘法并被合并成一个与 query 位置无关的 state：

[(QKT)⊙M]V≠Q(KTV).\left[(QK^{\mathsf T})\odot M\right]V \ne Q(K^{\mathsf T}V).
(T5)

Prefix state 可以递推计算，Si=Si−1+kiTviS_i=S_{i-1}+k_i^{\mathsf T}v_i，但逐 token recurrence 有长度为 NN 的串行依赖链。Lightning Attention 的 tiling 把这条链缩短到 block 数量：block 内用并行的 causal 左乘，block 之前的历史用累计 state 做右乘。忽略实际实现中的固定 decay 和 gate，报告的 block 形式为：

Ob=[(QbKbT)⊙MB]Vb+QbKVb−1,KVb=KVb−1+KbTVb.O_b= \left[(Q_bK_b^{\mathsf T})\odot M_B\right]V_b +Q_bKV_{b-1}, \qquad KV_b=KV_{b-1}+K_b^{\mathsf T}V_b.
(T7)

Block 内部仍是规则矩阵乘法，跨 block 只传递 d×dd\times d state。报告给出的时间复杂度为 O(Nd2+NBd)\mathcal O(Nd^2+NBd)。它提高了训练阶段的并行度，但 block 间仍存在 state 依赖；这里不应写成“causal recurrence 完全并行”。

2.3 Text-01 的实际 Lightning Attention 不是 GDN

Text-01 官方实现先对联合 QKV projection 应用 SiLU。对每个 layer/head，模型使用固定 decay ρl,h=exp(−λl,h)\rho_{l,h}=\exp(-\lambda_{l,h})：

[qt,kt,vt]=split(SiLU(xtWQKV)),St=ρl,hSt−1+ktTvt,zt=qtSt.[q_t,k_t,v_t]=\operatorname{split}(\operatorname{SiLU}(x_tW_{QKV})), \qquad S_t=\rho_{l,h}S_{t-1}+k_t^{\mathsf T}v_t, \qquad z_t=q_tS_t.
(T-Impl-1)

Attention 输出再经过 RMSNorm、input-dependent output gate 和 output projection：

ot=WO(σ(xtWG)⊙RMSNorm(zt)).o_t=W_O\!\left( \sigma(x_tW_G)\odot\operatorname{RMSNorm}(z_t) \right).
(T-Impl-2)

ρl,h\rho_{l,h} 由预设的 head slope 和 layer index 决定，不依赖当前 token。这里虽然有 σ(xtWG)\sigma(x_tW_G)，但它只控制读出后的 output，并不控制 state 的 decay/write。

Gated DeltaNet（GDN）的 state update 不同。先对旧 state 做 data-dependent decay，再用 key 对 state 的预测误差执行 delta correction：

St−=αtSt−1,v^t=ktSt−,St=St−+βtktT(vt−v^t).S_t^- = \alpha_t S_{t-1}, \qquad \widehat v_t=k_tS_t^-, \qquad S_t=S_t^-+\beta_t k_t^{\mathsf T}(v_t-\widehat v_t).
(GDN-1)

GDN 的 αt\alpha_t、βt\beta_t 由输入生成，并含有 vt−v^tv_t-\widehat v_t 这一 delta-rule correction。Text-01 没有这两项。因此它属于带固定 exponential decay 和 output gate 的 TransNormer/Lightning Attention 路线，不是后来 Qwen3-Next 等模型使用的 Gated DeltaNet。

实现核对：MiniMax-Text-01 官方 modeling code。`MiniMaxText01LightningAttention` 中的 decode recurrence 为 `kv = ratio * kv + kᵀv`，随后执行 RMSNorm、sigmoid output gate 与 output projection。

2.4 Hybrid 层补回检索能力

报告在 70M 至 7B 六种规模上比较 softmax、Lightning 与 hybrid-lightning。纯 Lightning 在常规任务上接近 softmax，但在 Needle in A Haystack（NIAH）上明显落后；周期性 full softmax 让模型重新读取原始 token 表示。

这组消融支持 Text-01 的 7:1 配置，但实验上限是 7B，不能直接证明 456B 模型在所有任务上与 full attention 等价。模型的 10 个 softmax 层还要保留随序列增长的 KV cache；“固定 state”只适用于 Lightning 层。

3. M2：回到 Full GQA

来源：MiniMax，The MiniMax-M2 Series: Mini Activations Unleashing Max Real-World Intelligence，v2，报告 §2.1、§2.2.2。

M2 是 62-layer decoder-only Transformer，最大训练上下文为 192K。每层都对完整 causal context 执行 attention，使用 48 个 query heads 和 8 个 KV heads。GQA ratio 为 6：每个 KV head 服务 6 个 query heads。

GQA 缩小了 KV cache，却不缩小 attention support。每个 query 仍访问全部历史位置，attention 主计算仍为：

FGQA(N)=2HqdhN2.F_{\mathrm{GQA}}(N)=2H_qd_hN^2.
(M2-1)

3.1 官方报告为什么放弃 hybrid

M2 报告给出两类原因。

  • Text-01 阶段的标准 benchmark 曾显示 hybrid 接近 full attention；模型扩大后，复杂 multi-hop reasoning 出现缺口。早期 proxy metric 与真实下游任务之间的相关性不够稳定。
  • Linear 和 sparse attention 的生产基础设施仍不成熟。报告列出的具体问题包括 memory-bound kernel、低精度 state 存储、prefix caching 和 speculative decoding 兼容性。

团队还训练了多种 sliding-window/full-attention hybrid。32K 内部分任务结果互有胜负；到 128K，完整历史覆盖的优势更清楚：

M2 Full Attention 与 Hybrid SWA 的关键对照
Benchmark Full attention Hybrid SWA
RULER 128K CWE 90.0 72.0
RULER 128K MQ 99.0 93.0
MTOB K-e BLEURT 60.0 45.0
MTOB e-k ChrF 44.8 27.2
SWE-verified（SFT） 54.7 50.2
Terminal-Bench（SFT） 26.7 23.8

M2 因此先用 full GQA 固定质量基线。报告同时判断，随着上下文继续增长、GPU compute scaling 放缓，sub-quadratic attention 仍会重新变得重要。

4. M3：MiniMax Sparse Attention（MSA）在 GQA 上增加 Block Selector

来源：Lai 等，MiniMax Sparse Attention，v2，报告 §2–§5.4。论文说明 MiniMax-M3 使用 MSA；其中的可控消融采用 109B MoE 实验模型。

MSA 保留 GQA 的 Q/K/VQ/K/V projection 和 scaled dot-product softmax，只增加轻量 Index Branch。Indexer 为每个 query 和 GQA group 选择 kk 个 KV blocks，Main Branch 只读取这些 blocks。同组的 query heads 共享 block indices，不同 groups 独立选择。

4.1 Index Branch 与 Main Branch

Index Branch 为每个 GQA group 生成一个 index query head，并让所有 groups 共享一个 index key head：

Qidx=XWqidx,Kidx=XWkidx.Q^{\mathrm{idx}}=XW_q^{\mathrm{idx}}, \qquad K^{\mathrm{idx}}=XW_k^{\mathrm{idx}}.
(MSA-5)

它先计算 token score，再对每个 block 做 max pooling，并选择 Top-K blocks：

Mi,bidx,(r)=maxj∈Bbj≤iQiidx,(r)(Kjidx)Tdidx,Ii(r)=TopKb(Mi,bidx,(r),k).M_{i,b}^{\mathrm{idx},(r)}= \max_{\substack{j\in\mathcal B_b\\j\le i}} \frac{Q_i^{\mathrm{idx},(r)} (K_j^{\mathrm{idx}})^{\mathsf T}} {\sqrt{d_{idx}}}, \qquad \mathcal I_i^{(r)}= \operatorname{TopK}_b(M_{i,b}^{\mathrm{idx},(r)},k).
(MSA-6)

包含 query 的 local block 始终被选中。Main Branch 随后只在 Ii(r)\mathcal I_i^{(r)} 覆盖的 causal tokens 上执行标准 softmax。稀疏近似发生在 selector；选中范围内的 attention 计算没有改变。

4.2 Indexer 训练

Top-K 不可微，因此 language-modeling loss 不能直接训练 index projections。MSA 用 KL loss，让 index distribution 拟合同一 GQA group 内 Main Branch 各 heads 的平均 attention distribution：

LKL=1NHkv∑i,rDKL(stopgrad(Pi(r))‖Piidx,(r)).\mathcal L_{\mathrm{KL}} =\frac{1}{NH_{kv}} \sum_{i,r} D_{\mathrm{KL}}\!\left( \operatorname{stopgrad}(P_i^{(r)}) \,\|\, P_i^{\mathrm{idx},(r)} \right).
(MSA-10)

Indexer 输入和 teacher distribution 都 detach，辅助 loss 只更新 index projections。训练先用 full attention 完成 indexer warmup，再启用 sparse Top-K；同一流程也能把 full-attention checkpoint 转成 MSA。

4.3 复杂度与实测结果

MSA 的 causal attention FLOPs 为：

FMSA(N)=HkvdidxN2+4HqdhNkBk.F_{\mathrm{MSA}}(N) =H_{kv}d_{idx}N^2 +4H_qd_hNkB_k.
(MSA-12)

Index Branch 仍有 N2N^2 项，但系数较小；Main Branch 的读取预算固定为 kBkkB_k。论文采用 Bk=128B_k=128、k=16k=16，即每个 query/group 最多读取 2,048 个 tokens。

在 109B/6B 实验模型上，MSA 使用 64 Q heads、4 KV heads。1M context 下，attention FLOPs 相对 GQA 减少 28.4 倍；H800 上的 attention kernel 实测 prefill 加速为 14.2 倍，decode 加速为 7.6 倍。

论文在相同 3T-token 预算下比较 Full、从头训练的 MSA-PT 和由 full checkpoint 转换的 MSA-CPT。三者整体表现接近，但差异仍随任务变化。MSA-CPT 在 128K 上相对 Full 的 HELMET Overall 为 -0.60，RULER Overall 为 +0.12，HELMET Rerank/RAG 为 -2.10。报告把 residual retrieval gap 列为后续问题。

KV cache 边界。MSA 需要让任意历史 block 保持可选，因此没有丢弃完整历史 K/V。它减少每个 query 实际读取的 KV 数量和 attention FLOPs；持久 KV cache 仍随序列长度增长。

5. 对照与结论

Text-01、M2 与 MSA 的机制对照
维度 Text-01 Lightning Hybrid M2 Full GQA M3 / MSA
Core attention 多数层为 linear recurrence；每 8 层有 1 层 full softmax 所有层 full softmax 选中 blocks 内为标准 softmax
历史访问 Lightning state 汇总历史；softmax 层直接读全部 token 每层直接读全部 token Indexer 扫描全部 blocks；Main Branch 读 Top-K blocks
长度相关主计算 70 层近似线性，10 层仍二次 二次 轻量 indexer 为二次项，Main Branch 为线性项
持久状态 Lightning 层固定 state；softmax 层 KV 随 NN 增长 全部层 KV 随 NN 增长 完整可选 K/V 随 NN 增长
主要风险 recurrent state 的检索损失 计算成本高 selector 漏选，固定 budget 不足

三次选择可以写成：

Lightning：压缩历史为 recurrent state⟶Full GQA：完整重读历史⟶MSA：先选择 blocks，再做 softmax.\text{Lightning：压缩历史为 recurrent state} \;\longrightarrow\; \text{Full GQA：完整重读历史} \;\longrightarrow\; \text{MSA：先选择 blocks，再做 softmax}.
(EVO-1)

Text-01 证明 linear attention 能扩展到数千亿参数模型；M2 的复杂任务评测暴露了 hybrid 的质量与基础设施风险；MSA 从 M2 的 GQA 基线出发，保留 softmax 主路径，只增加 block selector。MiniMax 在三代中调整的是完整历史访问、单位 token 成本和 GPU 实现之间的取舍。
