# 排序算法动画

## 打开页面

Monaco 编辑器和 C++ 高亮组件均打包在本地 `frontend/assets/`，页面无需 CDN。
使用仅监听本机地址的开发服务器，以正常加载编辑器 Worker 并自动保存源码：

```sh
cd /Users/xiejianan/sort-algo-demo
npm start
```

然后打开 <http://127.0.0.1:3000>。`Ctrl+C` 可停止服务器。
服务器提供静态资源和本地算法文件保存接口；修改的源码只发送给同源本机服务写入 `algorithms/`，不上传外部编译服务。C++ 编译、执行和轨迹采集仍在浏览器 WASM Worker 内完成。输出面板显示编译诊断和程序 stdout/stderr。
`file://` 无法可靠加载编译 Worker，请通过 HTTP 打开。静态文件可部署到 GitHub Pages，尚未实测线上部署。

## 编辑代码

- 每个算法使用独立的 Monaco C++ 文件模型，切换文件保留编辑、撤销历史与光标状态。
- 九个 `algorithms/*_sort.cpp` 是默认源码的唯一来源，前端与测试都读取这些文件。
- 本地编辑停止约 500ms 后自动写回对应 `.cpp`，状态栏显示待保存、保存中、已保存或失败；切换文件不会丢弃其他文件的待保存修改。已保存不等于已编译。
- 浏览器 localStorage 保留未保存草稿，刷新可恢复。恢复的旧草稿若无法确认对应磁盘版本，不会自动覆盖文件；外部编辑器改动导致版本冲突时同样保留草稿并停止写回，可先导出草稿，再确认重新载入磁盘文件。
- 保存失败可点击“重试保存”；关页前请确认状态为“已保存”，尚在等待或发送的修改不能保证落盘。
- GitHub Pages 没有本地保存接口，自动使用浏览器草稿模式，可编译、演示和导出 `.cpp`，但不会修改托管仓库。部署需包含根入口、整个 `frontend/` 和 `algorithms/`；仓库子路径使用相对 URL，线上部署尚未实测。
- 九种算法（冒泡、选择、插入、归并、快速、堆、希尔、梳、计数）均通过当前 C++ 的真实执行轨迹驱动动画，不再运行页面内的 JavaScript 排序模拟。
- 点击“编译并演示”：Clang 分析文本 AST → 自动插桩临时源码副本 → WASM 编译执行 → 校验完整 trace → 回放动画。Monaco 里的普通 C++ 不会被改写。
- 首次打开、切换算法和应用数组会自动准备轨迹。编辑源码或输入立即取消旧采集、停止动画并清除高亮；再次编译后，修改稿也显示真实执行行。
- 未修改源码和输入时，“重播”复用此次轨迹；“动作单步”推进一个动画动作，不是逐条 C++ 语句调试。动画完成仅控制回放，不阻塞已经完成的 C++ 执行。
- 连续比较/交换按元素身份复用抓钩：同一对柱子比较后交换不会重新抓取；只复用一个操作数时，对应抓钩保持闭合与位置，只移动另一个。选择排序中 `minIndex` 不变或刚更新时均适用；必要的跨越采用独立高位避让路径。写入、结束或取消会释放不再需要的抓钩。
- “编译运行”和 Ctrl/Cmd+Enter 保留普通执行模式，支持自定义 `main`；“编译并演示”使用界面数组与各文件排序函数入口，暂不支持自定义 `main`。
- 运行时展开输出正文；成功执行且退出码为 0 时自动折叠，将高度还给编辑器。点击“输出”可查看保留的完整日志；失败、超时、停止或非零退出码时展开正文。
- 变量栏只显示动作边界上可采集的整型/布尔变量，未采集的显示 `-`。已识别算法的变量名称会归一化显示；没有 clangd 语义补全。

## 算法关键状态标记

绿色表示已确定最终位置，蓝色表示局部有序，黄色表示候选、待插入元素或 pivot。快排使用蓝色/紫色表示小于/大于等于 pivot 的已扫描分区，图例相应切换为分区说明，不表示段内有序。区间括线与文字显示当前处理范围；希尔排序同时突出当前余数组，梳排序和希尔排序显示当前比较的 gap 跨距。计数排序显示真实桶计数和输出位置。

`trace-states.js` 使用 Clang AST 中的声明与引用绑定，将局部变量归一化后匹配九种已验证实现的完整 token 序列。规则忽略注释、空白和变量名称，但保留类型、常量、运算符、调用及控制流；这是一组保守的语义契约，不是任意 C++ 算法识别器。格式调整和变量重命名仍可识别；改变比较方向、循环写法、交换实现或增加其他语句后，普通动作轨迹仍可播放，阶段标记会停用，并在页面说明。

匹配后只对临时插桩副本增加阶段事件：冒泡每轮扫描结束；选择扫描后的候选和放置完成（包含不交换的轮次）；插入待插入元素和有序段；归并当前左右段及合并完成；快排分区、pivot 归位与递归基例；堆调整范围与取出堆顶；希尔/梳的 gap；计数的桶与写入游标。事件在真实 C++ 执行到该位置时产生，不预演排序，也不靠最终结果倒推轮次。

插入过程中蓝色段排除移动中的 key；归并 `rotate` 的动画分解期间暂停左右有序段声明，真实阶段边界到达后恢复。最终全绿还要求结果升序且保留输入多重集合。桶卡片显示非负的剩余数量，悬停显示 C++ 的真实计数；`while (count[value]-- > 0)` 失败时实际变量为 `-1`，表示桶已耗尽。修改源码或数组立即清除过期标记。

识别规则与工具链版本绑定。调整默认算法实现时，需审查并更新对应归一化契约和采集点，不能把磁盘当前编辑稿自动当成已验证模板。`test:trace` 覆盖九种算法、六组输入、阶段不变量、九种变量重命名及中文注释、修改逻辑停用标记、绿色柱子的实际位置和抓钩复用。

## 追踪边界

支持现有九个模板中的整型数组比较/读取/赋值、可证明的连续三语句交换、`std::swap`、`std::rotate`、递归、lambda 和计数桶 `++/--`。归并中的一次真实 `rotate` 会分解为相邻移动演示，不冒充 C++ 内部实际执行的多次 `swap`。

这是受限的动作识别器，不是完整 C++ 调试器。数组指针别名/逃逸、未知库函数读写数组、宏生成动作、带副作用的比较、复合数组写入、下标中的函数调用或嵌套数组等会拒绝演示，输出原源码诊断；普通编译仍可使用这些写法。不会静默回退到模板动画。

trace 写入独立 WASM 文件，不混入用户 stdout。源码上限 128 KiB，数组 1–12 个 1–99 整数（页面输入目前至少 2 个）；AST/trace 各最多 8 MiB，trace 最多 10,000 事件，程序运行最多 5 秒，超限可停止和重试。该隔离用于协议校验，不宣称防范恶意 C++ 伪造 trace。

## 重新构建与检查

首次安装或修改 `scripts/monaco-entry.js` 后：

```sh
npm ci
npm run build
npm test
npm run test:wasm
npm run test:trace
```

`scripts/monaco-entry.js` 只打包 C++ 高亮及常用编辑功能，`frontend/js/code-editor.js` 管理文件模型和动画行标记，`source-store.js` 管理源码加载、草稿和自动保存。
`frontend/js/trace-source.js` 是绑定本地 Clang 版本的 AST/改写层，`frontend/runtime/trace-runtime.hpp` 是临时采集运行时，`trace-events.js` 校验轨迹并适配抓钩动作。新增模块作为普通静态资源加载，无需重新构建工具链。

`test:trace` 使用实际生产 Clang/lld/WASM 执行，九个模板各六组输入对照原始/插桩结果，并将真实事件送入 GSAP/DOM stub 验证柱子的最终位置。浏览器视觉、Monaco 交互及真实 GitHub Pages 部署需另行验收；不能把 Node 外壳测试等同于浏览器验收。
编辑器采用 [Microsoft Monaco Editor](https://github.com/microsoft/monaco-editor)（MIT），
许可证与第三方声明保留在 `frontend/assets/Monaco-LICENSE.txt` 和 `frontend/assets/Monaco-ThirdPartyNotices.txt`。
DOMPurify 覆盖为已修复版本 3.4.16，避免 Monaco 0.57.0 所固定的 3.4.15 的已知问题。

## 目录

```text
frontend/       页面、样式、JS 动画、编辑器、编译与 trace、资源及许可证
algorithms/     九种排序的 C++ 函数源码（编译驱动自动补全头文件和 main）
tests/          编辑器、动画、编译、trace、保存及 HTTP 接口测试
  fixtures/     核心回归测试使用的固定动画与 C++ 测试样例
scripts/        本地服务、Monaco 构建和 WASM 工具链下载脚本
index.html      根目录入口，转到 frontend/index.html
```

`npm test` 包含保存状态和安全接口回归；HTTP 测试只写临时项目，不修改真实算法文件。本地服务只允许固定九个算法 ID，校验来源和写入令牌，并通过版本检查和临时文件重命名避免已检测的覆盖与半文件写入。外部编辑器不参与锁协议，版本检查不等于跨进程事务锁。
